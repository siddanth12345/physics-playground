# Splinter Showdown

make a 3d game about tables, first person fps type game where you shoot splinters at another bot which is a table, the splinters make the table smaller and smaller essentially making it harder to hit, the splinter shoots 24 bullets and finishes all after 5 seconds(just to show you shooting rate) and make the health 100. each splinter does 5 damage, you can also do sheild by pressing e which lasts for 4 seconds, make a giant living room type stage and make q dash. left click is a scope for shooting, also make the crosshair green
